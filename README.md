# NumPy Census Income Analysis

## Project Overview

This project focuses on analyzing census-related data using **NumPy**, a fundamental Python library for numerical computing and data analysis. The dataset contains **1,000 records and 8 columns**, including age, education level, race, sex, capital gain, capital loss, working hours per week, and income category.

The main objective of this project is to use NumPy to perform numerical analysis, statistical calculations, data filtering, and comparisons to understand different patterns within the census data.

## Dataset Features

The dataset contains the following variables:

- **age** – Age of the individual
- **education-num** – Numerical representation of education level
- **race** – Encoded race category
- **sex** – Encoded gender category
- **capital-gain** – Capital gains received
- **capital-loss** – Capital losses incurred
- **hours-per-week** – Number of hours worked per week
- **income** – Encoded income category

## Objectives

- Load and analyze census data using NumPy.
- Understand the structure and numerical characteristics of the dataset.
- Calculate statistical measures such as mean, median, minimum, maximum, and standard deviation.
- Analyze age, education, income, and working-hour patterns.
- Filter records based on specific conditions.
- Perform NumPy array operations and calculations.
- Compare numerical variables across different income categories.
- Identify useful patterns and insights from the census data.

## Key NumPy Concepts Used

- NumPy arrays
- Array indexing and slicing
- Boolean filtering
- `np.mean()`
- `np.median()`
- `np.min()`
- `np.max()`
- `np.std()`
- `np.sum()`
- `np.unique()`
- Conditional operations
- Aggregation and statistical analysis

## Conclusion

This project demonstrates how **NumPy can be used for numerical data analysis** on a real-world census dataset. By applying array operations, statistical functions, filtering, and aggregation techniques, the project helps identify patterns related to age, education, working hours, capital gains/losses, and income.

The project provides practical experience in using NumPy as a foundation for more advanced data-analysis libraries such as **Pandas, Matplotlib, and Seaborn**.
